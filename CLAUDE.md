## Architecture

This is a **Nuxt 3** photo-guessing game. The user pastes a Google Sheets URL, and the app loads photo+name data from that sheet, then presents a carousel of photos with multiple-choice name options.

### Data flow

1. `app.vue` — entry point. Accepts a Google Sheets URL, extracts the sheet ID via regex, and renders either a setup card or the game.
2. `components/PickUP.vue` — core game component. On mount, it:
   - Fetches the Google Sheet using `google-spreadsheet` with a hardcoded API key
   - Expects column layout: `[?, googleDriveShareLink, ?, name]` (0-indexed: `[1]` = Drive link, `[3]` = name)
   - Extracts the Google Drive file ID from the share URL's `?id=` param
   - Proxies images through `https://image.virgil246.eu.org/?url=` (self-hosted [wsrv.nl](https://wsrv.nl) instance) to bypass Google Drive CORS/auth restrictions
   - Shuffles rows and generates multiple-choice options for each
   - Tracks guesses and emits `guess-add` with `{ opt, ans }` to parent for score tracking
3. `components/LargerPic.vue` — wraps an image in an AlertDialog with `VueMagnifier` for zoom on click.

### Key design decisions

- `choicesNum` (slider, 3–10) controls how many options appear per question; passed as a prop from `app.vue`
- Options are generated by `getNumbersFromRangeWithSpecific`: picks `choicesNum-1` wrong answers + the correct one, then shuffles
- `showAnswer` prop toggles green/red coloring on buttons after the user clicks "答案和分數"
- Score is computed in `app.vue` from the `guessedPeople` array (items where `ans === true`)

### UI stack

- **shadcn-nuxt** (`components/ui/`) — shadcn components (Card, Button, Carousel, Slider, etc.)
- **Tailwind CSS** via `@nuxtjs/tailwindcss`
- **radix-vue** — headless primitives underlying shadcn
- **embla-carousel-vue** — carousel used in `PickUP.vue`
- `lib/utils.ts` — standard `cn()` helper (clsx + tailwind-merge)
